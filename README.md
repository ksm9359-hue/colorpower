# Dodge Rain

간단한 캐주얼 회피 게임입니다. 좌우로 이동하면서 낙하물을 피하고 점수를 최대한 높이세요.

## 빠른 시작

```bash
npm install
npm run dev
```

브라우저에서 표시된 로컬 주소를 열면 게임이 실행됩니다.

## 조작 방법

- 이동: `Left` / `Right` 또는 `A` / `D`
- 재시작: `Space` (게임 오버 후)
